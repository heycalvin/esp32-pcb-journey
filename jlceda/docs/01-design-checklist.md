# 📋 PCB 硬件设计自检清单 (Design Checklist)

在每次完成原理图与 PCB 绘制、准备投板打样前，务必逐项核对以下清单：

---

## 1. 原理图设计检查 (Schematic Check)

- [ ] **电源设计**
  - [ ] 主电源输入端是否配备瞬态保护（TVS / 自恢复保险丝 PPTC）及防反接二极管/MOS。
  - [ ] 稳压芯片（LDO / DCDC）输入输出端是否按手册放置了足够容量的滤波电容与去耦电容（大小电容搭配，如 10μF + 0.1μF）。
  - [ ] ESP32 芯片 3.3V 供电轨瞬态峰值电流能否达到 500mA 以上。
- [ ] **复位与下载电路**
  - [ ] `EN` (CHIP_PU) 引脚是否有 RC 上电延时复位电路（一般 10kΩ 上拉 + 1μF/0.1μF 下拉电容）。
  - [ ] `GPIO0` (BOOT) 引脚是否有上下拉控制电路或双三极管/MOS 自动下载控制电路（DTR/RTS 控制）。
- [ ] **Strapping 引脚状态**
  - [ ] 检查所有 Boot / Strapping 引脚在上电瞬间的默认电平状态，避免外设电路干扰上电时序。
- [ ] **电气规则检查 (ERC)**
  - [ ] 运行嘉立创EDA专业版 **设计 -> 电气规则检查 (ERC)**，确保无未连接引脚、悬空网络或网络重名。

---

## 2. PCB 布局布线检查 (Layout & Routing Check)

- [ ] **元器件布局**
  - [ ] 遵循“先大后小、核心优先、信号流向顺畅”原则。
  - [ ] 去耦电容是否紧挨着芯片电源引脚放置，并优先经过电容再进入引脚。
  - [ ] 发热元件（LDO、DCDC、功率电感）是否有良好的散热焊盘并铺铜散热。
- [ ] **RF 天线区域规范 (关键!)**
  - [ ] 板载 PCB 天线（或模组天线区域）下方及周边所有电气层必须**挖空（Keep-out 禁铜）**，不能有走线、铺铜或金属外壳阻挡。
  - [ ] 天线最好伸出板边，或放置在板卡边缘。
- [ ] **走线与电源地完整性**
  - [ ] 走线避免直角或锐角，统一采用 45° 倒角或圆弧走线。
  - [ ] 电源线线宽是否足够（一般信号线 6~10mil，电源线 15~30mil 或铺铜）。
  - [ ] 地铜是否完整，避免大面积地平面被走线割裂，适当打地过孔降低阻抗。
- [ ] **设计规则检查 (DRC)**
  - [ ] 线宽、线距、孔径、孔到线距离是否满足嘉立创工艺标准（如线宽线距 ≥ 0.127mm/5mil，最小过孔内径 ≥ 0.3mm）。
  - [ ] 运行嘉立创EDA专业版 **设计 -> DRC 检查**，确保零错误 (0 Errors, 0 Warnings)。

---

## 3. 生产出图与工艺自检 (Fabrication Check)

- [ ] **丝印与装配**
  - [ ] 极性元件（二极管、电解电容、LED、IC 一脚）是否有清晰的丝印标记。
  - [ ] 丝印文字大小合适（字符高度 ≥ 0.8mm，线宽 ≥ 0.15mm），且没有压在焊盘上。
  - [ ] 标注板卡版本号、作者名称、制作日期以及接口功能说明。
- [ ] **嘉立创下单文件**
  - [ ] 导出 Gerber 文件并使用 Gerber 查看器二次确认各层显示正常。
  - [ ] 若需要 SMT 贴片，导出 BOM 清单与 Pick & Place 坐标文件并核对元器件匹配度。
