# 第 05 章：眼睛与交互——OLED 屏与拨轮按键

在这一章，我们要探究小智的“眼睛”与“触觉”：**0.91 寸 I2C OLED 屏幕** 与 **三向拨轮按键开关**。

---

## 👀 1. 0.91 寸 OLED 屏幕：为什么它是小智的最佳搭档？

- **分辨率**：$128 \times 32$ 像素，黑白/单色。
- **OLED 自发光优势**：每个像素点自己发光，不需要背光板，所以纯黑背景极度深邃、省电、对比度超高。
- **驱动芯片**：经典的 **SSD1306**，开源社区驱动库（如 U8g2、Adafruit_SSD1306）生态极为繁荣。

---

## 🤝 2. 什么是 I2C 协议？（两人对讲机模型）

上一章我们学的 I2S 是用来传音频的，而 **I2C (Inter-Integrated Circuit)** 则是用来传输控制命令和显示数据的轻量级总线。

```plaintext
┌─────────────────────────────────────────────────────────────┐
│                       I2C 对讲机模型                        │
│                                                             │
│  [ SCL (串行时钟线) ] ──> 呼叫对讲节拍（双方约定说话节奏）   │
│  [ SDA (串行数据线) ] ──> 真正对话内容（发指令、传图像数据） │
└─────────────────────────────────────────────────────────────┘
```

### I2C 的三大神奇特性：
1. **只需要 2 根线**：`SCL` + `SDA`，加上电源 `VCC` 和 `GND`，一共只要 4 根线就能驱动一块屏幕！
2. **总线一主多从**：ESP32（主机）可以在同一对 SCL/SDA 线上挂接多个从机设备（如温湿度传感器、陀螺仪、屏幕），只要每个从机设备的 **I2C 芯片地址**（如 OLED 默认是 `0x3C`）不同，就不会打架。
3. **必须加上拉电阻 (Pull-Up Resistor)**：
   - I2C 总线是“开漏输出 (Open-Drain)”结构。
   - 必须在 SCL 和 SDA 线上分别接一个 **4.7kΩ 或 10kΩ 电阻上拉到 3.3V**（通常小智使用的 OLED 模块板载已经自带了这两颗电阻）。

---

## 🕹️ 3. 拨轮按键开关 (Wheel Switch)：指尖的灵动交互

小智使用了一颗 **三向滚轮按键 (拨轮开关)**：
- 向上拨动（Volume +）
- 向下拨动（Volume -）
- 向下按下（单击打断说话 / 长按进入配网模式）

```plaintext
              3.3V
               │
            [10kΩ] (上拉电阻)
               │
ESP32 GPIO ────┴───[ 按键触点 ]─── GND
```

### 为什么按键要加上拉电阻？
- 当你**没有按下**按键时，GPIO 引脚通过 10kΩ 电阻连到 3.3V，读取到稳定的 **高电平 (1)**。
- 当你**按下按键**时，按键闭合直接短路到 GND，GPIO 引脚被强行拉成 **低电平 (0)**。
- 这样 ESP32 就能通过检测电平是从 1 变 0，精准识别出按键被按下了！
