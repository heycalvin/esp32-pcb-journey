## 1. PCB 诞生的七个完整阶段

一块硬件电路板从零到拿到手，经历如下标准生命周期：

```plaintext
1. 需求与方案设计  → 明确功能（如：做一块带 Type-C 的 ESP32-C3 开发板）
2. 原理图设计 (SCH) → 用符号把电阻、电容、芯片按电气逻辑连起来
3. 封装匹配 (Footprint) → 给每个原理图符号绑定现实中的物理焊盘尺寸
4. PCB 布局布线 (PCB) → 在二维板框内摆放器件，连铜线，铺地铜
5. 规则检查 (DRC)   → 软件自动检测是否短路、断路或线距不符合工厂工艺
6. 生产出图与下单   → 导出 Gerber/BOM，嘉立创打样或 SMT 贴片
7. 焊接与上电点灯   → 用万用表量电压，烧录程序验证
```

---

## 2. 为什么选择“嘉立创EDA 专业版”？

- **云端与本地同步**：支持随时随地打开工程，多人协作或本地离线模式。
- **立创商城器件库直连**：原理图符号、PCB 封装、3D 模型、立创物料编号（LCSC Part #）一键调用，不用自己痛苦画封装。
- **与嘉立创打样无缝对接**：一键下单打样、一键匹配 SMT 贴片元器件库。

## 3. 极速上手：创建你的第一个工程

### Step 1: 下载与登录
1. 访问 [嘉立创EDA官网](https://lceda.cn/) 下载 **嘉立创EDA专业版 (EasyEDA Pro)** 桌面客户端。
2. 注册并登录嘉立创账号。

### Step 2: 新建工程
1. 点击左上角 **文件 -> 新建 -> 工程**。
2. 工程名称输入：`01_esp32_c3_minimal_system`。
3. 保存位置选择本地或个人工作区。

### Step 3: 认识核心界面与常用快捷键
- **原理图常用快捷键**：
  - `W`：绘制导线 (Wire)
  - `R`：旋转元器件 (Rotate 90°)
  - `N`：放置网络标签 (Net Label - 非常重要，不用长距离连线，同名网络自动相连)
  - `Shift + F`：立创商城 / 元器件库搜索
  - `Space`：翻转 / 旋转
- **PCB 常用快捷键**：
  - `W`：开始布线 (Route Track)
  - `V`：打过孔 (Via - 顶层底层换层)
  - `B`：重建铺铜 (Rebuild Copper)
  - `Alt + 3`：切换 3D 视图查看立体效果
