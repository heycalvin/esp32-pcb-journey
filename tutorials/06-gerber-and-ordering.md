# 06. 投产篇：免费打样与 SMT 贴片下单

---

## 1. 嘉立创“免费打样”与省钱攻略

- **每月免费打样券**：嘉立创通常向个人用户提供每月免费打样额度（长宽 10cm x 10cm 以内，双层板/部分四层板）。
- **SMT 贴片选型省钱秘籍**：
  - 尽量选择**立创基础库 (Basic Parts)** 或 **常用库 (Extended/Preferred)** 元器件。
  - 基础库元器件**免收换料费/工程费**，贴片费用极低。

---

## 2. 嘉立创EDA专业版“一键下单”流程

因为使用的是嘉立创EDA专业版，生产下单非常傻瓜化：

1. 点击顶部菜单栏 **制造 -> PCB 制板 / SMT 下单**。
2. 页面会自动调起嘉立创下单助手或网页端，并自动上传最新生成的 Gerber 文件。
3. **关键制板参数选择**：
   - 板子层数：2 层板（或 4 层板）
   - 板子数量：5 片
   - 阻焊颜色：经典绿色、哑光黑、骚气紫、中国红等（大部分颜色免费）
   - 表面处理：有铅喷锡 / 无铅喷锡（建议无铅或沉金）
   - 铜厚：1 oz
4. **如果选择自己手工焊接**：只需下单 PCB 裸板，并在立创商城按 BOM 买散件元器件即可。
5. **如果选择嘉立创 SMT 贴片代工**：
   - 勾选 SMT 贴片。
   - 确认元器件与立创元器件编号匹配度。
   - 查看 3D 贴片效果图（检查芯片方向、引脚是否对齐）。
   - 支付并等待发货（通常 2~3 天顺丰包邮到家）。
