## 💡 新手必知的两句话

1. **“先用模组，不要直接裸片画芯片”**：ESP32 官方模组（如 ESP32-WROOM-32E / ESP32-C3-WROOM）内部已经集成调好晶振、Flash 和天线阻抗匹配，初学者选用模组可以将成功率直接提升到 100%。
2. **“原理图是骨骼，PCB 是血肉”**：原理图关注“电气逻辑连通”，PCB 关注“物理走线与空间布局”。只要原理图逻辑正确，PCB 再根据规则走线，就绝不会翻车。
