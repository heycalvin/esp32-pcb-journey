# 03. 封装篇：原理图转 PCB 与封装检查

很多硬件新手最大的困惑是：**“为什么原理图画好了，转到 PCB 却乱成一团，甚至打样出来焊不上？”**  
核心就在于**封装 (Footprint)** 的概念。

---

## 1. 搞懂“符号 (Symbol)”与“封装 (Footprint)”

- **原理图符号 (Symbol)**：给工程师看的电气图纸（例如一个画着两个引脚的电阻方块）。
- **PCB 封装 (Footprint)**：现实物理世界中元器件在板子上的**金属焊盘形状、大小、间距与引脚编号**（例如 0603 电阻、SOT-23-5 三极管、Type-C 接口插拔脚）。

> 💡 **核心黄金法则**：原理图引脚编号（1, 2, 3...）必须与 PCB 封装的焊盘编号（1, 2, 3...）严格一一对应！

---

## 2. 嘉立创EDA专业版的巨大优势

在嘉立创EDA专业版中，只要你是在 **立创商城库 (SZLCSC)** 选型的元器件：
1. 原理图符号、PCB 封装、3D 模型是**官方自动绑定好**的。
2. 每个器件都附带真实库存、单价与立创物料编号（Cxxxxx）。
3. 新手完全不需要手动画封装，直接选型即可直接转 PCB！

---

## 3. 新手选型封装推荐指南 (贴片焊接难度)

| 元件类型 | 推荐封装 | 新手友好度 | 说明 |
| :--- | :--- | :---: | :--- |
| **电阻 / 电容** | **0603 (1608公制)** 或 0805 | ⭐⭐⭐⭐⭐ | 大小适中，手焊用普通烙铁就能焊，也可以选 SMT 贴片 |
| **LDO 稳压器** | **SOT-23-5** 或 SOT-223 | ⭐⭐⭐⭐⭐ | 引脚间距大（0.95mm），极易手焊 |
| **轻触按键** | **3x4x2.0 SMD** 或 3x6 侧按键 | ⭐⭐⭐⭐⭐ | 4 焊盘，布局方便 |
| **Type-C 接口** | **16P 贴片/双排插针** | ⭐⭐⭐⭐ | 优先选手工好焊接的带定位柱款，或直接 SMT 贴片 |
| **串口芯片** | **CH343P (ESSOP-10)** 或 CH340N | ⭐⭐⭐⭐ | 尽量避免新手手焊 QFN 无引脚封装，除非选 SMT |
| **ESP32 模组** | **邮票孔 (Castellated)** | ⭐⭐⭐⭐ | 两侧大焊盘，烙铁拖焊或风枪轻松焊接 |

---

## 4. 原理图转 PCB 步骤

1. 在原理图界面，点击顶部菜单 **设计 -> 原理图转 PCB**（或按快捷键 `Alt + X`）。
2. 系统会弹窗显示网络和元件列表，点击 **应用更改 (Apply Changes)**。
3. 此时所有元器件的物理封装会被放置在 PCB 画布旁边，并且器件之间有密密麻麻的细白线（**飞线 / Ratsnest**）。
4. **什么是飞线？**  
   飞线代表原理图上连接好、但在 PCB 上**尚未实际走铜线**的电气网络。当你把所有的飞线都用实际铜线连好后，飞线就会自动消失！
