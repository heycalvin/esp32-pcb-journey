# 05. 检查篇：DRC 规则检查与 3D 渲染

在把板子发给工厂之前，必须进行最后的质量体检。

---

## 1. 嘉立创工艺参数与 DRC 规则配置

进入菜单栏 **设计 -> 设计规则 (Design Rules)**，检查如下常用参数：

| 规则项 | 嘉立创标准工艺推荐值 | 说明 |
| :--- | :---: | :--- |
| **最小线宽 (Min Track Width)** | `6 mil` (0.152mm) | 免费/经济打样支持到 5~6 mil |
| **最小线距 (Min Clearance)** | `6 mil` (0.152mm) | 铜线与铜线、铜线与焊盘间距 |
| **最小过孔孔径 (Via Hole Size)** | `0.3 mm` (12 mil) | 过孔钻孔大小 |
| **最小过孔外径 (Via Diameter)** | `0.5 mm` ~ `0.6 mm` | 过孔金属环外径 |

---

## 2. 运行 DRC 检查 (Design Rule Check)

1. 点击快捷键或菜单 **设计 -> 运行 DRC 检查**。
2. 查看左下角的 **DRC 结果列表**：
   - 🔴 **错误 (Error)**：如网络短路 (Short)、飞线未接完 (Unconnected)、间距过近 (Clearance Violation) —— **必须清零！**
   - 🟡 **警告 (Warning)**：如文字压在焊盘上、未封闭走线 —— 检查并逐一修复。
3. 点击每个错误条目，画布会自动高亮定位到具体位置。

---

## 3. 丝印层整理 (Silkscreen)

- 将所有元器件标号（R1, C1, U1...）拖放到清晰可见的地方，**绝不能压在焊盘或过孔上**（工厂在焊盘上打丝印会被削掉或导致假焊）。
- 标注引脚功能丝印（如 `TX`, `RX`, `3V3`, `GND`, `IO0`, `IO1`...），方便插线调试。
- 增加个性化 Logo 或项目名称，例如 `ESP32 Journey v1.0` 和你的名字。

---

## 4. 3D 渲染与干涉检查

1. 按快捷键 `Alt + 3`（或菜单 **视图 -> 3D 预览**）。
2. 在 3D 模式下旋转查看：
   - Type-C 接口是否朝外？
   - 按键高度是否合适？
   - 排针是否会挡住其他器件？
   - 丝印文字方向是否统一、美观？
