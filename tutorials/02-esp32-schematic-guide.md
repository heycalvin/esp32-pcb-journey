# 02. 原理图篇：ESP32 最小系统五大模块

一个能够独立运行、支持一键烧录代码的 ESP32 最小系统，由以下 **5 大核心功能模块** 组成：

```plaintext
┌─────────────────────────────────────────────────────────────┐
│                     ESP32 最小系统                          │
│                                                             │
│  [1. Type-C 接口] ──(5V)──> [2. LDO 电源 (3.3V)] ────────┐  │
│          │                                                │  │
│     (USB D+/D-)                                           ▼  │
│          ▼                                            ┌──────┴──────────┐
│  [3. 自动下载与串口芯片 (CH343P / CH340K)] ─────────> │                 │
│          │  (TX/RX, DTR/RTS)                          │  5. ESP32 模组  │
│          ▼                                            │  (ESP32-C3 /    │
│  [4. 复位与 Boot 控制电路 (EN / IO0 按键)] ─────────> │   WROOM-32E)    │
│                                                       └─────────────────┘
└─────────────────────────────────────────────────────────────┘
```

---

## 模块一：Type-C 供电与接口模块

### 1. 电路原理与注意点
- 选用 **16P 或 6P Type-C 接口**（新手推荐 16P 或简易 6P 供电封装）。
- **必须接 CC1 和 CC2 下拉电阻**：在 CC1、CC2 引脚分别接一个 **5.1kΩ (0402/0603)** 电阻下拉到 GND。否则用 C-to-C 线（如 Mac/快充头）插上后会无法识别并不供电！
- 加一个 **0.5A~1A 自恢复保险丝 (PPTC)** 和一个 **TVS 静电保护二极管**（保护板子不会被静电或短路击穿）。

---

## 模块二：5V 转 3.3V 电源管理 (LDO)

### 1. 选型建议
- ESP32 启动 Wi-Fi 时瞬间峰值电流可达 400~500mA，必须选择最大输出电流 $\ge 600\text{mA}$ 的低压差线性稳压器。
- **推荐型号**：
  - **ME6211C33M5G** (SOT-23-5，低静态功耗，立创常用库)
  - **AMS1117-3.3** (SOT-223，价格极便宜，电流大，但静态功耗稍高)

### 2. 经典滤波电路
```plaintext
VBUS (5V) ────┬───[ LDO 输入端 (VIN) ]───[ LDO 输出端 (VOUT) ]───┬──── 3V3
             │                                                  │
           [10μF]                                             [10μF]
           电容(去低频)                                        电容(去低频)
             │                                                  │
           [0.1μF]                                            [0.1μF]
           电容(去高频)                                        电容(去高频)
             │                                                  │
            GND                                                GND
```

---

## 模块三：USB 转串口与一键自动下载电路

### 1. 选型推荐
- **CH343P** (推荐)：免外部晶振，内置上拉，支持高速，QFN/ESSOP封装。
- **CH340K / CH340N**：极简外围，SOP-8/ESSOP-10，不需要外接晶振。

### 2. 自动下载核心原理
开发环境（如 ESP-IDF / Arduino IDE）在烧录固件时，会自动拉低 DTR/RTS 信号，通过两颗 NPN 三极管（或数字三极管 / 双三极管 UM6K1N）组合控制 ESP32 的 `EN` 和 `IO0`：
- 先把 `IO0` 拉低，再瞬间拉低并释放 `EN` 复位，ESP32 就会自动进入 **Bootloader 下载模式**。
- 烧录完毕后释放，ESP32 自动运行新程序，全程无需手动按按键！

---

## 模块四：复位 (EN) 与 Boot 按键电路

### 1. EN 上电 RC 延时
- 在 `EN` 引脚接一个 **10kΩ 上拉电阻到 3.3V**，并接一个 **1μF (或 0.1μF) 电容到 GND**。
- 保证 3.3V 电源稳定上升完成后，EN 引脚才升为高电平，防止芯片因电源没就绪而死锁。

### 2. 手动按键
- 放一个轻触按键（K1）连接 EN 到 GND（按下即手动硬件复位）。
- 放一个轻触按键（K2）连接 IO0 到 GND（按住再复位可手动进下载模式）。

---

## 模块五：ESP32 核心模组与排针引出

### 1. 推荐模组
- **ESP32-C3-WROOM-02** (RISC-V 架构，集成 Wi-Fi 4 + BLE 5，引脚少，布线简单，初学者首选！)
- **ESP32-WROOM-32E** (双核 Xtensa，经典万能款)

### 2. 排针引出 (Header)
- 将模组两侧的 GPIO、ADC、I2C、UART 以及 3.3V、5V、GND 引出到标准 **2.54mm 单排针**，方便后续插面包板调试各种传感器。

## 5. 嘉立创EDA专业版原理图绘制实战步骤

1. 打开工程，点击 **新建 -> 原理图**。
2. 按快捷键 `Shift + F` 调出立创商城元器件库。
3. 搜索并放置对应器件（立创基础库/常用库优先）。
4. 放置完成后按 `W` 绘制连接导线，或按 `N` 放置网络标签（如 `3V3`, `GND`, `TXD`, `RXD`, `EN`, `IO0`）。
5. 点击菜单栏 **设计 -> 电气规则检查 (ERC)**，确保 0 错误。
6. 点击 **设计 -> 原理图转 PCB**！
