## 🔍 五大核心子系统硬件原理解析

### 1. 声音输入系统：INMP441 (I2S 数字麦克风)
- **原理**：直接输出数字 I2S 信号给 ESP32-S3，无需经过外置 ADC 或模拟放大电路，抗干扰能力强、底噪极低。
- **关键走线引脚**：
  - `SCK / BCLK` (串行时钟)
  - `WS / LRCK` (左右声道选择/帧时钟)
  - `SD / DOUT` (串行数据输出)
  - `L/R` (接 GND 选择左声道，接 VDD 选择右声道)

### 2. 声音输出系统：MAX98357A (I2S D类数字音频功放) + 2308 腔体喇叭
- **原理**：接收 ESP32-S3 解码出来的大模型 TTS 语音 PCM 数字流，直接转为高保真音频信号驱动 2308 扬声器。
- **关键引脚**：`BCLK`, `LRCK`, `DIN`, `GAIN`, `SD_MODE`。
- **布线注意**：功放输出到喇叭的两根差分走线应尽量粗且等长，远离高频敏感信号。

### 3. 显示与人机交互系统
- **0.91 寸 OLED 屏**：I2C 接口（仅需 `VCC`, `GND`, `SCL`, `SDA` 4 根线），用于呈现灵动的眼睛表情和对话文字。
- **三脚拨轮开关 / 按键**：提供单击、长按、滚轮切换功能（如打断对话、调节音量、配网）。

### 4. 电源与充放电管理系统
- **模块方案**：采用成熟的 5V 锂电池充放电一体模块（集成充电管理 + 5V 同步升压）。
- **开关**：配合 `MSK12C02` 侧拨开关控制整机供电通断。

## 🛠️ 如何在嘉立创EDA专业版中打开与学习？

### 第一步：导入工程到嘉立创EDA
1. 打开 **嘉立创EDA (专业版)** 客户端。
2. 点击左上角 **文件 -> 打开 -> 打开工程 (或导入)**。
3. 选择本地文件路径：`d:\code\sanbox\esp32-pcb-journey\hardware\01-xiaozhi-ai\ProPrj_AI-xiaozhi.epro`。
4. 此时左侧工程树中将完整呈现：
   - 📄 **原理图**：可双击打开查看各个元器件连接逻辑。
   - 🖲️ **PCB 板**：可双击打开查看顶层/底层走线、板框尺寸与铺铜。

### 第二步：对照学习四部曲
1. **看布局 (Layout)**：观察麦克风（INMP441）和喇叭（2308）的位置分布，为什么麦克风通常和喇叭拉开距离并做声学隔离？（防止喇叭声音直接串扰进麦克风产生回音）。
2. **看走线 (Routing)**：观察 I2S 高速数字音频信号线的走线路径、5V 和 3.3V 电源线宽。
3. **看 3D 渲染**：在 PCB 编辑器中按 `Alt + 3` 预览整板立体效果，观察各个元器件的高度和机械配合。
4. **看生产文件 (Gerber)**：了解目录下导出的 `.GTL` (顶层铜箔), `.GBL` (底层铜箔), `.GTO` (顶层丝印), `.DRL` (钻孔文件) 是如何对应到 PCB 各个物理层的。

## 📦 物料清单与打样文件对照

| 制造文件 | 对应图层 | 作用 |
| :--- | :--- | :--- |
| `Gerber_TopLayer.GTL` | 顶层走线层 (Top Layer) | 顶层所有铜箔走线与焊盘 |
| `Gerber_BottomLayer.GBL` | 底层走线层 (Bottom Layer) | 底层所有铜箔走线与铺铜 |
| `Gerber_TopSilkscreenLayer.GTO` | 顶层丝印层 (Top Silkscreen) | 元器件位号、文字与标识 |
| `Gerber_TopSolderMaskLayer.GTS` | 顶层阻焊层 (Top Solder Mask) | 绿油开窗（露铜上锡区域） |
| `Gerber_BoardOutlineLayer.GKO` | 边框层 (Board Outline) | PCB 外形切割尺寸 |
| `Drill_PTH_Through.DRL` | 导通孔钻孔文件 (Drill) | 所有金属化过孔与插针孔 |
