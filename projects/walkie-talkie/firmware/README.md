# 📻 ESP32-S3 ESP-NOW 对讲机 (Walkie-Talkie) ESP-IDF 固件

本项目基于 **ESP-IDF v5/v6** 原生驱动框架，利用 **ESP-NOW** 数据链路层直通协议与现代 **I2S (IDF 5.x/6.x new driver)** 音频流驱动，打造超低延迟（<5ms）、免连 Wi-Fi 路由器的双向无线语音对讲机系统。

已在 **DOIT ESPS3-32 N16R8（ESP32-S3 双核 240MHz + 16MB Flash + 8MB Octal PSRAM）** 开发板与面包板 MVP 上完成 100% 硬件验证与全链路闭环测试。

---

## 🔌 硬件引脚分配 (DOIT ESPS3-32 N16R8)

开发板放置在面包板旁，以**黑色天线朝上、两个 Type-C 朝下**为正向基准：

### 1. INMP441 数字麦克风 (I2S 全双工录音输入)
| INMP441 引脚 | 开发板引脚 | 实物排针位置 | 电气特性与说明 |
| :--- | :--- | :--- | :--- |
| **`VDD`** | **`3V3`** | **左侧 L01** | ⚡ **3.3V 供电（严禁接 5V，防烧 MEMS）** |
| **`GND`** | **`GND`** | **右侧 R01** | 系统参考地 |
| **`L/R`** | **`GND`** | **右侧 R01** | 接地选定左声道采样 |
| **`SD`** (DOUT)| **`GPIO 2`** | **右侧 R05** | I2S 数字音频串行数据输入 |
| **`WS`** (LRCK)| **`GPIO 42`** | **右侧 R06** | I2S 左右声道选择时钟 (8kHz) |
| **`SCK`** (BCLK)| **`GPIO 41`** | **右侧 R07** | I2S 位时钟 (256kHz, 32-bit slot) |

> 💡 **跳线技巧**：开发板右侧第 5、6、7 脚正好是连续的 `2`、`42`、`41`，杜邦线顺次排布，极为工整。

### 2. MAX98357A D类功放模块 (I2S 扬声器放音输出)
| MAX98357A 引脚 | 开发板引脚 | 实物排针位置 | 电气特性与说明 |
| :--- | :--- | :--- | :--- |
| **`Vin`** | **`3V3`** | **左侧 L02** | ⚡ **3.3V 供电（规避 5Vin 防倒灌二极管隔离硬伤）** |
| **`GND`** | **`GND`** | **左侧 L22** | 系统参考地 |
| **`DIN`** | **`GPIO 15`** | **左侧 L08** | I2S 数字音频串行数据输出 |
| **`BCLK`** | **`GPIO 16`** | **左侧 L09** | I2S 位时钟 (256kHz, 32x LRCLK 锁频) |

> 💡 **跳线技巧**：功放所有引脚全部集中在开发板**左侧排针**，`15`、`16`、`17` 是紧邻的三个引脚，信号线与麦克风物理隔离，杜绝串扰。

### 3. PTT 按键与板载 WS2812 炫彩状态指示灯
| 器件 | 开发板引脚 | 实物排针位置 | 逻辑与状态机 |
| :--- | :--- | :--- | :--- |
| **PTT 轻触按键** | **`GPIO 4`** | **左侧 L04** | 内部配置弱上拉；接线采用**对角线接法**对地短接，按压拉低到 0V 触发通话 |
| **WS2812 RGB LED**| **`GPIO 48`** | **板载集成** | 由 ESP-IDF `led_strip` 专享 RMT 驱动控制 |

#### 🌈 WS2812 状态指示协议
- 🔵 **常亮蓝色 (Blue)**：待机监听中（Standby），随时准备接收空中无线音频；
- 🟢 **常亮绿色 (Green)**：按住 PTT 说话中（PTT Talking），麦克风采集中并广播；
- 🔴 **常亮红色 (Red, 持续 2 秒)**：松开按键后触发“通话结束”状态倒计时，2 秒后自动回归待机蓝灯。

## 🛠️ 编译与烧录指令 (ESP-IDF v6)

激活 ESP-IDF 环境变量后，进入固件工程目录：

```bash
cd projects/walkie-talkie/firmware

# 1. 设置目标芯片为 ESP32-S3 (若首次编译)
idf.py set-target esp32s3

# 2. 编译工程
idf.py build

# 3. 烧录并进入串口监视器 (macOS 示例端口 /dev/cu.wchusbserial*)
idf.py -p /dev/cu.wchusbserial* flash monitor
```

> [!TIP]
> 退出串口监视器快捷键：`Ctrl + ]`。

## 🧪 运行模式与分步验证

在 `main/app_config.h` 中通过宏开关无缝切换工作模式：

```c
/* ====================================================================
 * 运行模式配置
 * 0: 完整 ESP-NOW 双向对讲机模式 (Walkie-Talkie)
 * 1: 本地硬件自环测试模式 (Local Loopback: 麦克风直接出扬声器，排查接线)
 * ==================================================================== */
#define APP_MODE_WALKIE_TALKIE      0
#define APP_MODE_LOCAL_LOOPBACK     1

#define CURRENT_APP_MODE            APP_MODE_LOCAL_LOOPBACK
```

---

### 阶段 1：单机硬件自环测试 (`APP_MODE_LOCAL_LOOPBACK`)
**微信语音条模式（按住录音，松开回放）**：
1. 将 `CURRENT_APP_MODE` 设为 `APP_MODE_LOCAL_LOOPBACK`；
2. 编译并烧录至第 1 块开发板；
3. 上电复位，喇叭发出约 0.4 秒的清脆 1000Hz 自检蜂鸣音，WS2812 亮蓝色；
4. **按住 PTT 按键**（灯变绿）：对着麦克风说话，语音被实时存入内部 RAM 环形缓冲，本地喇叭强制静音（杜绝啸叫）；
5. **松开按键**（灯变红）：喇叭立即大声清晰回放刚刚录制的声音；回放完毕 2 秒后红灯变回蓝灯。

---

### 阶段 2：双机 ESP-NOW 实时对讲 (`APP_MODE_WALKIE_TALKIE`)
**隔空超低延迟对讲**：
1. 将 `CURRENT_APP_MODE` 切换为 `APP_MODE_WALKIE_TALKIE`；
2. 将该固件分别烧录进 **两块开发板**（板 A 与板 B）；
3. 双方均通电（插充电宝或电脑）：
   - 板 A 和板 B 开机均呈现 🔵 **待机蓝灯**；
   - **板 A 按下 PTT**（变 🟢 绿灯）：对着板 A 麦克风说话，板 A 本地喇叭静音，板 B 扬声器**实时同步大声播报**（端到端延迟 <30ms）；
   - 板 A 松开 PTT（板 A 变 🔴 红灯 2 秒后转蓝）；
   - **板 B 按下 PTT**（变 🟢 绿灯）：反向对讲同理。

## 🔬 底层核心关键技术沉淀

1. **MAX98357A 32x 锁相环（PLL）突破**：
   - 芯片硬件规格要求时钟必须为 $32\times$、$48\times$ 或 $64\times$ LRCLK，且 $BCLK \ge 243.2\text{ kHz}$；
   - 采用立体声双槽镜像传输（Stereo Mirrored），$BCLK = 8000 \times 32 = 256\text{ kHz}$，成功破除功放芯片低频静音锁死。
2. **单一 3.3V 逻辑与供电同源**：
   - 规避部分开发板 USB 供电时 `5Vin` 排针因防倒灌二极管而断电的问题，功放与麦克风全走 `3V3` 稳压轨，底噪干净纯粹。
3. **一阶高通 DC-Blocker 滤波**：
   - INMP441 麦克风静音时存在约 1200 的直流偏置；
   - 驱动内置数字高通滤波算法 $y[n] = x[n] - x[n-1] + \frac{127}{128}y[n-1]$，彻底滤除 0Hz 直流分量，消除静态功耗与爆音。
4. **声学正反馈抑制（半双工硬件互锁）**：
   - 本地按下 PTT 发射时强制切断本地 I2S TX DMA 输出，彻底阻断麦克风与喇叭之间的自激啸叫正反馈回路。
