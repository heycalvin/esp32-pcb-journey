# 📌 DOIT ESPS3-32 N16R8 开发板全 44 引脚速查指南

本工程实物硬件主控采用 **DOIT（创思通信）出品的 ESPS3-32 N16R8（顶配版：16MB Flash + 8MB Octal PSRAM）**，具备双 Type-C 接口（UART 调试口与 USB-JTAG 原生口）。

为方便后续扩展开发，本手册基于实物正面视角（**黑色天线朝上、Type-C 接口朝下**）记录所有引脚的电气属性与功能。

---

## 🗺️ 引脚全景对照图（实物正向视角）

```text
                     【顶端：黑色 PCB 天线】
                     ┌──────────────────┐
    (3.3V 输出) L01  [ 3V3 ]      [ GND ] R01 (系统地)
    (3.3V 输出) L02  [ 3V3 ]      [ TX  ] R02 (U0TXD)
   (复位/重启) L03  [ RST ]      [ RX  ] R03 (U0RXD)
 🔘(PTT按键)   L04  [  4  ]      [  1  ] R04 (GPIO 1)
               L05  [  5  ]      [  2  ] R05 🎙️(麦克风 SD)
               L06  [  6  ]      [ 42  ] R06 🎙️(麦克风 WS)
               L07  [  7  ]      [ 41  ] R07 🎙️(麦克风 SCK)
 🔊(功放 DIN)  L08  [ 15  ]      [ 40  ] R08 (GPIO 40)
 🔊(功放 BCLK) L09  [ 16  ]      [ 39  ] R09 (GPIO 39)
 🔊(功放 LRC)  L10  [ 17  ]      [ 38  ] R10 (GPIO 38)
               L11  [ 18  ]      [ 37  ] R11 (GPIO 37)
               L12  [  8  ]      [ 36  ] R12 (GPIO 36)
               L13  [  3  ]      [ 35  ] R13 (GPIO 35)
               L14  [ 46  ]      [  0  ] R14 (BOOT 按键)
               L15  [  9  ]      [ 45  ] R15 (GPIO 45)
               L16  [ 10  ]      [ 48  ] R16 🌈(板载 WS2812 彩灯)
               L17  [ 11  ]      [ 47  ] R17 (GPIO 47)
               L18  [ 12  ]      [ 21  ] R18 (GPIO 21)
               L19  [ 13  ]      [ 20  ] R19 (USB D+)

                     └──────────────────┘
                      [USB]        [UART]
                   原生JTAG接口   调试/烧录口(插电脑)
```

## 📋 左侧排针引脚表 (L01 ~ L22)

| 引脚编号 | 丝印标号 | 芯片内部硬件 | 功能说明与电气特性 | 对讲机 MVP 项目角色 |
| :---: | :---: | :--- | :--- | :--- |
| **L01** | **`3V3`** | 3.3V 稳压输出 | 板载 LDO 输出，最大驱动电流 500mA | ⚡ **接 INMP441 麦克风 `VDD`** |
| **L02** | **`3V3`** | 3.3V 稳压输出 | 内部并联的 3.3V 电源轨，与 L01 同源 | ⚡ **接 MAX98357A 功放 `Vin`**（实测 USB 供电最稳，声音洪亮） |
| **L03** | **`RST`** | 芯片复位 (EN) | 接地拉低触发硬件复位，连接板载 RST 按键 | 复位按键 |
| **L04** | **`4`** | GPIO 4 | 通用数字 IO / ADC1_CH3，内部开启弱上拉 | 🔘 **接 PTT 按键（按下对讲）** |
| **L05** | **`5`** | GPIO 5 | 通用数字 IO / ADC1_CH4 | 空闲（可用于 OLED 屏） |
| **L06** | **`6`** | GPIO 6 | 通用数字 IO / ADC1_CH5 | 空闲（可用于 OLED 屏） |
| **L07** | **`7`** | GPIO 7 | 通用数字 IO / ADC1_CH6 | 空闲 |
| **L08** | **`15`** | GPIO 15 | 高速数字 IO / ADC2_CH4 | 🔊 **接 MAX98357A 功放 `DIN`** |
| **L09** | **`16`** | GPIO 16 | 高速数字 IO / ADC2_CH5 | 🔊 **接 MAX98357A 功放 `BCLK`** |
| **L10** | **`17`** | GPIO 17 | 高速数字 IO / ADC2_CH6 | 🔊 **接 MAX98357A 功放 `LRC`** |
| **L11** | **`18`** | GPIO 18 | 通用数字 IO / ADC2_CH7 | 空闲 |
| **L12** | **`8`** | GPIO 8 | 通用数字 IO / ADC1_CH7 | 空闲 |
| **L13** | **`3`** | GPIO 3 | 通用数字 IO / ADC1_CH2 | 空闲 |
| **L14** | **`46`** | GPIO 46 | 启动配置引脚 (Strapping)，ESP32-S3 仅作为输入 | 空闲 |
| **L15** | **`9`** | GPIO 9 | 通用数字 IO / ADC1_CH8 | 空闲 |
| **L16** | **`10`** | GPIO 10 | 通用数字 IO / ADC1_CH9 | 空闲 |
| **L17** | **`11`** | GPIO 11 | 通用数字 IO / ADC2_CH0 | 空闲 |
| **L18** | **`12`** | GPIO 12 | 通用数字 IO / ADC2_CH1 | 空闲 |
| **L19** | **`13`** | GPIO 13 | 通用数字 IO / ADC2_CH2 | 空闲 |
| **L20** | **`14`** | GPIO 14 | 通用数字 IO / ADC2_CH3 | 空闲 |
| **L21** | **`5Vin`** | 外部 5V 供电输入 | ⚠️ **注意**：Type-C USB 供电时防倒灌二极管隔离，该脚**不输出 5V**；外接独立 5V 适配器时生效 | 备用 5V 输入（单板测试勿接） |
| **L22** | **`GND`** | 系统参考地 | 内部大面积铺铜连通 | ⚡ **接 MAX98357A 功放 `GND`** |
