# 第 03 章：耳朵系统——INMP441 与 I2S 数字音频输入原理

在这一章，我们要探究小智的“耳朵”：**INMP441 全向数字麦克风模块**。

---

## 🎙️ 1. 传统模拟麦克风 vs INMP441 数字麦克风

很多初学者以前接触过普通的驻极体话筒（就是两个脚的圆柱小咪头）：
- **传统模拟麦克风**：输出的是极其微弱的毫伏级模拟连续波形，非常容易被周围的 Wi-Fi 射频、电源波动干扰，而且单片机需要额外的运放放大和 ADC 转换芯片，底噪很大。
- **INMP441 数字麦克风 (MEMS)**：
  - 芯片内部直接集成了声学传感器、前置放大器和 24 位高精度模数转换器 (ADC)。
  - 输出的是纯粹干净的 **数字音频流 (I2S)**，抗干扰能力极强，声音清晰通透！

---

## ⏱️ 2. 什么是 I2S 协议？（节拍器与传送带）

I2S (Inter-IC Sound) 是专门在芯片之间传输高保真音频的数字通信协议。  
用生活比喻来理解它的 **3 根核心信号线**：

```plaintext
┌─────────────────────────────────────────────────────────────┐
│                      I2S 传送带模型                         │
│                                                             │
│  [ SCK / BCLK (时钟节拍) ] ──> 节拍器滴答响，每响一下运 1 个比特 (0或1)│
│  [ WS / LRCK (声道切换)  ] ──> 左右轨道道岔，高电平运右耳，低电平运左耳 │
│  [ SD / DOUT (音频数据)  ] ──> 真正载满声音 0/1 数据的传送带包裹     │
└─────────────────────────────────────────────────────────────┘
```

1. **SCK / BCLK (Bit Clock，位时钟)**：
   - 就像工厂流水线的传送节拍器。节拍器跳动一下，就从数据线上读出一位二进制数据（0 或 1）。
2. **WS / LRCK (Word Select / Left-Right Clock，左右声道选择)**：
   - 指示当前传送带上运送的是左声道声音还是右声道声音。
3. **SD / DOUT (Serial Data Out，串行数据输出)**：
   - 实际运送声音波形采样数据的“货物传送带”。
4. **L/R (Left/Right Channel Select)**：
   - 硬件引脚，直接接 GND（设为左声道）或接 VDD（设为右声道）。小智单声道单麦克风直接接地即可。

## 🔌 3. INMP441 在原理图上的接线表

在小智的原理图中，INMP441 模块引脚与 ESP32-S3 核心板的对应关系如下：

| INMP441 模块引脚 | 信号含义 | 连接到 ESP32-S3 / 电源 | 说明 |
| :--- | :--- | :--- | :--- |
| **VDD** | 3.3V 供电 | 连接系统 `3V3` 稳压轨 | 必须提供干净平稳的 3.3V |
| **GND** | 电源地 | 连接系统 `GND` | 电源与信号参考地 |
| **L/R** | 左右声道模式选择 | 连接 `GND` | 单麦配置为左声道采集 |
| **SCK / BCLK** | I2S 位时钟 | 连接 ESP32-S3 `GPIO42` (举例) | 由 ESP32 主机产生节拍 |
| **WS / LRCK** | I2S 左右声道时钟 | 连接 ESP32-S3 `GPIO41` | 由 ESP32 主机切换帧时钟 |
| **SD / DOUT** | I2S 声音数据输出 | 连接 ESP32-S3 `GPIO2` | 麦克风输出音频流给 ESP32 |
