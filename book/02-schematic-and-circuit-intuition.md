# 第 02 章：电路小白的第一堂课——原理图里的基本符号与电路规律

在深入研究各个芯片之前，我们需要建立最基础的**电路直觉**。  
只要掌握了以下四个核心概念，你就能看懂 90% 的原理图！

---

## 🌊 1. 水流模型：电压、电流与接地 (GND)

把电路想象成一个城市自来水系统：

```plaintext
┌─────────────────────────────────────────────────────────────┐
│                 自来水系统 vs 电子电路系统                  │
│                                                             │
│   水塔高度 (水压差)  ─────────>  电压 (Voltage, 例如 5V, 3.3V)│
│   水管里的水流速度  ─────────>  电流 (Current, 例如 500mA)  │
│   水龙头与水龙头开关 ─────────>  电阻 / 开关 (控制流量与通断)│
│   大海 / 排水总管   ─────────>  地 (GND / 0V，一切水流的归宿)│
└─────────────────────────────────────────────────────────────┘
```

- **没有电压差就没有电流**：水必须从高处（5V / 3.3V）流向低处（GND）。
- **GND (Ground/地)** 是整个电路板所有信号的“基准海平面”。所有元器件的负极都要接回 GND。

## 📻 2. 原理图连线秘籍：导线 vs 网络标签 (Net Label)

在原理图上，要把两个引脚连起来有两种方法：

### 方法一：用导线硬连 (Wire)
- 按快捷键 `W` 直接画一条绿色的线连过去。
- **缺点**：如果两个器件距离很远，满屏幕都是穿插交叉的线，图纸会变成一团乱麻。

### 方法二：网络标签（隔空传音，极力推荐！）
- 按快捷键 `N` 放置一个名字相同的网络标签（如给两个引脚都贴上 `I2S_BCLK` 标签）。
- **规则**：**只要名字一模一样，EDA 软件就认为它们在物理上是直接连通的！**
- 这就是为什么你在小智原理图上看到很多芯片看似孤零零放着，其实通过相同名字的标签（如 `3V3`, `GND`, `SDA`, `SCL`）已经在背后全部接通了。

## 🧰 3. 电阻与电容：电路里的两员大将

```plaintext
      电阻 (Resistor)                         电容 (Capacitor)
  ┌───[ 10kΩ ]───┐                           ┌───┤├───┐
      限流 / 分压                             蓄水 / 滤波 (去噪)
```

### (1) 电阻 (Resistor - 单位：Ω / kΩ)
- **生活比喻**：水龙头上的限流节水器。
- **核心作用**：
  - **限流**：LED 发光二极管如果直接接 3.3V 会瞬间烧毁，串联一个 1kΩ 电阻就能把水流限制在安全范围。
  - **上拉 / 下拉**：给悬空的引脚一个确定的高电平（3.3V）或低电平（GND），防止引脚受空气中电磁干扰随机乱跳。

### (2) 电容 (Capacitor - 单位：μF / nF / pF)
- **生活比喻**：每个芯片家门口放的“应急小水桶”和“高频细筛子”。
- **核心作用（滤波去耦）**：
  - 当 ESP32 突然开启 Wi-Fi 发射大功率时，供电电压可能会瞬间被拉低；此时芯片旁边的 10μF 大电容立刻放水补偿，稳住电压。
  - 高频毛刺杂音会被 0.1μF (100nF) 小电容直接导入地（GND），保证芯片吃到纯净平稳的电源。
