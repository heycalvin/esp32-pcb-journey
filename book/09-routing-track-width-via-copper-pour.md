# 第 09 章：PCB 布线实战——线宽、过孔与铺地铜

布线（Routing）就是把铜皮做成导线，把各个焊盘连通的过程。

---

## 🚰 1. 线宽选择：水管粗细论

很多新手习惯用默认的 8mil 线宽把所有线一走到底，这是不对的。

```plaintext
┌──────────────┬────────────────────────┬──────────────────────────────────────────┐
│   网络类型   │        推荐线宽        │                 通俗解释                 │
├──────────────┼────────────────────────┼──────────────────────────────────────────┤
│ 普通信号线   │ 8 mil ~ 10 mil (0.2mm) │ 像细吸管，流淌微弱的 0/1 信号，灵活好拐弯 │
│ 5V 主电源线  │ 20 mil ~ 30 mil(0.6mm) │ 像自来水主管道，电流大，线太细会引起压降 │
│ 喇叭输出差分 │ 15 mil ~ 20 mil        │ 承载音频功率电流，两根线尽量平行走线     │
│ GND (地)     │ 铺铜 (全板自动连接)    │ 汪洋大海，不需要手动走线，依靠铺铜搞定   │
└──────────────┴────────────────────────┴──────────────────────────────────────────┘
```

---

## 🕳️ 2. 什么是“打过孔 (Via)”？（立体立交桥）

双层板有两层可以走线：
- **顶层 (TopLayer - 红色)**
- **底层 (BottomLayer - 蓝色)**

当你在顶层走线时，如果前方被另一根红色的线挡住了去路：
1. 按快捷键 `V`（或按数字键 `2`）。
2. EDA 软件会放置一个打通顶层和底层的金属小圆孔——这就是 **过孔 (Via)**！
3. 铜线立刻从红色穿入孔中变成蓝色，在底层走过去，绕过障碍后再打一个过孔穿回顶层！

---

## 📐 3. 走线美学铁律：永远不拐 90° 直角

- ❌ **严禁直角与锐角**：直角在板厂做微米级化学蚀刻时容易积留酸液导致铜箔变细甚至断开，还会产生高频信号反射。
-  **统一 45° 倒角或圆弧拐弯**：走线圆润流畅，优雅美观，电气性能优良。

---

## 🛡️ 4. 铺铜 (Copper Pour)：给电路板撑起保护伞

当所有红色、蓝色的信号线都连好后，板子上还有很多空白区域：
1. 顶层和底层分别画一个 **多边形铺铜区 (Copper Area)**，网络选择 `GND`。
2. 按快捷键 `B` (Rebuild Copper)。
3. 所有空白区域都会被接地的铜箔紧紧包围！
4. **铺铜三大好处**：
   - 全板接地阻抗几乎为 0，抗干扰能力拉满。
   - 帮助发热芯片（如升压模块、LDO）向全板散热。
   - 保护信号线免受外界 Wi-Fi 杂波干扰。
