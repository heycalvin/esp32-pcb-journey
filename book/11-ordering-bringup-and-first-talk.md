# 第 11 章：投产与测试——免费打样与上电点灯

---

## 🎁 1. 嘉立创“免费打样”下单实操

因为使用的是嘉立创EDA专业版，下单极其简单：

1. 点击菜单 **制造 -> PCB 制板 / SMT 下单**。
2. 网页会自动上传 Gerber 文件并解析板子尺寸（例如 $50\text{mm} \times 45\text{mm}$，长宽在 10cm 以内完全符合免费券标准）。
3. **参数选择**：
   - 板子数量：`5 片`
   - 板子层数：`2 层板`
   - 颜色：根据个人喜好选（黑色高冷、紫色优雅、经典绿色）
4. 在结算页勾选 **每月免费打样券**，0 元顺丰包邮到家！

---

## 🛑 2. 收到板子后的“防炸机”四步检测法 (Bring-up)

收到快递开箱后，**千万不要直接插 USB！** 请务必走完四步：

```plaintext
┌─────────────────────────────────────────────────────────────┐
│                    硬件 Bring-up 四步法                     │
│                                                             │
│  第 1 步：静态冷测 ──> 用万用表蜂鸣档测 5V-GND、3V3-GND 是否短路│
│  第 2 步：空载通电 ──> 插电用万用表直流电压档量 5V 和 3.3V 稳不稳│
│  第 3 步：摸温测试 ──> 用手背轻触芯片，确认完全不烫手       │
│  第 4 步：烧录固件 ──> 连电脑串口，刷入小智 AI 官方固件    │
└─────────────────────────────────────────────────────────────┘
```

---

## 🤖 3. 刷入固件与小智初次对话

1. 将 ESP32-S3 核心板插上电脑 Type-C 口。
2. 打开小智 AI 网页端烧录工具（或使用 ESP-IDF / VSCode）。
3. 选择串口号，一键烧录小智固件。
4. 手机连接小智发射出的 Wi-Fi 热点，进入网页输入家里的 Wi-Fi 账号密码和你的 AI 大模型 Key。
5. 听到小智传来清脆的提示音：**“联网成功，我是小智，很高兴认识你！”**  
   同时 0.91 寸 OLED 屏幕亮起可爱的眨眼表情！
